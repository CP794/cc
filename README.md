# 坦克大战 Tank Battle 🎮

一个使用纯 HTML + CSS + JavaScript（Canvas）编写的经典坦克大战游戏，无需任何依赖，双击打开即可游玩。

## ✨ 功能特性

- 🕹️ **经典玩法**：控制坦克移动与射击，保护基地、消灭所有敌人
- 🧱 **多种地形**：可破坏的砖墙、坚不可摧的钢墙、水域、可藏身的树林
- 🤖 **敌人 AI**：敌方坦克会追踪玩家并自动开火
- 🏆 **关卡系统**：共 5 关，敌人数量随关卡递增
- 💥 **特效与音效**：爆炸粒子特效 + Web Audio 合成音效
- 🎨 **像素风格**：Canvas 绘制，无外部资源

## 🎮 操作方式

| 按键 | 功能 |
|------|------|
| `W` `A` `S` `D` / 方向键 | 移动 |
| `空格` / `J` | 发射子弹 |
| `P` | 暂停 / 继续 |

## 🚀 如何运行

直接在浏览器中打开 `index.html` 即可开始游戏，无需安装任何东西。
